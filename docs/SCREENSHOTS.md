# 截图拍摄清单

PRD 与 README 引用的截图全部放在 `docs/screenshots/`，文件名严格按下方清单命名。每张图拍好后替换占位即可。

> 拍摄前请先用 `flutter build windows` 构建 Release 版本运行，保证画质与正式发布一致。

---

## 必拍截图（6 张）

### 01-splash.png · 启动页 / 主页

- **拍什么**：app 启动后的主界面，显示已有精灵卡片网格 + "新建精灵"按钮
- **建议状态**：至少有 2-3 个精灵（小雨 demo + 1-2 个自定义），让卡片有内容
- **PRD 引用**：§7.1
- **重点**：体现"你已经拥有的精灵"和"创建新精灵"两个核心入口

### 02-text-custom.png · 文生图创建

- **拍什么**：文生图创建页，已选好性别 + 气质 + 风格，prompt 预览框可见
- **建议状态**：填入示例气质如"温柔、倔强、爱笑"，风格选"明亮阳光"
- **PRD 引用**：§7.2
- **重点**：让 prompt 预览框的内容清晰可见，体现"用户输入关键词 → AI 立刻合成日漫立绘"

### 03-photo-custom.png · 图生图创建

- **拍什么**：图生图创建页，已上传一张照片，保留人物特征转日漫立绘
- **建议状态**：用一张正面清晰的肖像照，立绘生成结果与照片人物特征（五官、发型、神态）对应可见
- **PRD 引用**：§7.3
- **重点**：体现"照片 → 立绘"的转换过程，而不是文生图

### 04-spirit-awakening.png · 精灵唤醒界面

- **拍什么**：新精灵首次进入房间时的"唤醒"瞬间——精灵从沉睡到睁眼的过渡状态
- **建议状态**：用新生成的自定义精灵（如罗罗），截到精灵立绘已显示、但还没开始正式对话的那一刻
- **PRD 引用**：§7.4
- **重点**：体现"ta 刚醒过来"的仪式感，是 Lumora "思念具象化"叙事的关键一帧

### 05-chat.png · 聊天页

- **拍什么**：精灵房间 + 对话气泡，体现精灵立绘 + reaction 触发后的状态
- **建议状态**：聊几句让精灵命中一条 seed 记忆（例如小雨的"奶茶店"），截到精灵回复"半糖去冰对吧"那一条
- **PRD 引用**：§7.5
- **重点**：右上角书本图标（记忆编辑入口）要清晰可见

### 06-memory-editor.png · 精灵记忆编写界面

- **拍什么**：记忆编辑页（editMode=true），预填已有 seed memories，展示"新增一条 + 删除一条"的中间态
- **建议状态**：展示 profile 文本框 + 多张记忆卡片（标题/内容/标签/重要度），体现编辑能力
- **PRD 引用**：§7.6
- **重点**：体现用户可以 App 内 DIY 记忆，不需要手写 md 文件

## 拍摄注意事项

1. **分辨率**：建议 1920×1080 或更高，PNG 格式
2. **隐私**：截图里不要露出 API key 文件、真实个人路径、其他应用窗口
3. **精灵形象**：用 demo 立绘（mao.png / bai.png）或已生成的自定义精灵即可
4. **对话内容**：用 demo Memory.md 里的内容（奶茶店、地铁、火锅），不要用真实私人对话
5. **文件位置**：`docs/screenshots/01-splash.png` 等，与 PRD/README 引用路径一致
