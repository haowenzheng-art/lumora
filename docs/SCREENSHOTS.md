# 截图拍摄清单

PRD 与 README 引用的截图全部放在 `docs/screenshots/`，文件名严格按下方清单命名。每张图拍好后替换占位即可。

> 拍摄前请先用 `flutter build windows` 构建 Release 版本运行，保证画质与正式发布一致。

---

## 必拍截图（5 张）

### 01-splash.png · 启动页

- **拍什么**：app 启动后的主界面，显示已有精灵卡片网格 + "新建精灵"按钮
- **建议状态**：至少有 2-3 个精灵（小雨 demo + 1-2 个自定义），让卡片有内容
- **PRD 引用**：§7.1

### 02-text-custom.png · 文生图创建

- **拍什么**：文生图创建页，已选好性别 + 气质 + 风格，prompt 预览框可见
- **建议状态**：填入示例气质如"温柔、倔强、爱笑"，风格选"明亮阳光"
- **PRD 引用**：§7.2

### 03-chat.png · 聊天页

- **拍什么**：精灵房间 + 对话气泡，体现精灵立绘 + reaction 触发后的状态
- **建议状态**：聊几句让精灵命中一条 seed 记忆（例如小雨的"奶茶店"），截到精灵回复"半糖去冰对吧"那一条
- **PRD 引用**：§7.3
- **重点**：右上角书本图标（记忆编辑入口）要清晰可见

### 04-memory-onboarding.png · 记忆初始化

- **拍什么**：新建精灵时的"让 ta 先认识你"页面，profile 文本框 + 至少 2 张记忆卡片已填
- **建议状态**：profile 填一段示例印象，2 张记忆卡填示例内容（如"下雨没带伞"）
- **PRD 引用**：§7.4

### 05-memory-editor.png · 聊天页记忆编辑

- **拍什么**：从聊天页右上角点开后进入的记忆编辑页（editMode=true），预填已有 seed memories
- **建议状态**：展示"新增一条 + 删除一条"的中间态，体现编辑能力
- **PRD 引用**：§7.5

## 可选截图（后续补）

### 06-blink.png · 眨眼瞬间

- 连拍精灵闭眼那一帧，体现图层分解效果
- 拍摄难度高（眨眼只持续 70ms），可用屏幕录像截帧

### 07-video-loop.png · 视频无缝循环

- 录屏 10 秒以上，体现双 player 交叉淡入无缝循环
- 静态截图无法体现，建议用 GIF 或短视频

### 08-crisis-probe.png · 危机关切性追问

- 输入"活着真没什么意思"，截精灵的关切性追问回复
- 注意：不要触发到明确危机（否则会输出 `[[CRISIS_BREAK]]` 标记），保持模糊语境

---

## 拍摄注意事项

1. **分辨率**：建议 1920×1080 或更高，PNG 格式
2. **隐私**：截图里不要露出 API key 文件、真实个人路径、其他应用窗口
3. **精灵形象**：用 demo 立绘（mao.png / bai.png）或已生成的自定义精灵即可
4. **对话内容**：用 demo Memory.md 里的内容（奶茶店、地铁、火锅），不要用真实私人对话
5. **文件位置**：`docs/screenshots/01-splash.png` 等，与 PRD/README 引用路径一致
