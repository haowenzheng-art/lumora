## 2024-12-XX · 雪天地铁围巾

冬天大雪那天，明远忘戴围巾，我把自己的解下来给他。后来他把围巾弄丢了，气了我两天。他偷偷在淘宝买了一条一样的山寨想蒙混过关，以为我看不出来。
