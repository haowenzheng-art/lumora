### 2. 偏好设置页 4 个开关

页面布局（自上而下）：

- 顶部 TopBar：左箭头返回 + "偏好设置"标题
- 简介文案："这里是 Lumora 的几个产品感细节。关掉任何一个都不会影响核心功能，只是少一些'在活着'的感觉。"
- 4 个开关（卡片式）：
  - 破冰淡入 / 立绘从透明渐变显形的过程
  - 自动进入对话 / 立绘显形后自动跳到对话页（关闭后需手动点击）
  - 打字机效果 / 精灵消息逐字出现并闪烁光标
  - 骨架屏 / 生成等待时的流光占位

每个开关右侧是 Switch（打开=琥珀色，关闭=灰色玻璃色）。

### 3. 开关 → 行为验证（默认全关）

| 测试 | 步骤 | 预期 |
|---|---|---|
| 破冰淡入 ON | 开开关 → 重启 App → 选精灵 | 立绘瞬间显形，无 800ms 渐变 |
| 破冰淡入 OFF | 关开关 → 重启 App → 选精灵 | 立绘 800ms 淡入（默认） |

| 打字机 OFF | 关开关 → 重启 App → 选精灵 → 等它说话 | 消息逐字 + 闪烁光标（默认） |
| 骨架屏 ON | 开开关 → 触发一次"生成"等待 | 占位是空 SizedBox，无 shimmer 流光 |

## 已知行为 / 设计决策

1. **实时生效**：改开关后再进入对应页面才会生效。当下停留在的页面不会立即重建。
2. **默认行为不变**：4 个开关默认全关（=v2.2 默认行为），老用户升级零感知。
3. **强制眨眼（forceBlinkToken）**：v2.3 启动补丁，独立于偏好开关，每次立绘完全显形都会触发一次，让"刚醒过来"不再靠碰巧。
4. **布局占位**：关掉骨架屏时仍保留原 width/height 占位，避免后续元素位置跳变。
