# v2.2-D 打字机效果手动测试流程

> **改动概述**：`_MessageBubble` 加打字机支持——新增消息（助手消息）以 35ms/字逐字出现，附闪烁光标（琥珀色 2px 竖线，600ms 周期 AnimatedOpacity）。长消息可点"跳过"按钮立即显示完整。ChatPage 维护 `_typewriterIndex` 追踪"当前正在打字"的消息索引，完成后回调重置。
>
> **改动文件**：
> - `lib/main.dart` — `_MessageBubble` 加 `typewriter` + `onTypewriterComplete` 参数，内部 `Timer.periodic(35ms)` 推字符；ChatPage 加 `_typewriterIndex` state；5 处 add 助手消息位置（opening / probe / LLM 返回 / LLM 异常 / greeting）设置 `_typewriterIndex`
>
> **设计选择**：
> - **打字速度 35ms/字**：中文每分钟约 60-80 字（人眼自然语速），符合 Lumora"陪伴"调性
> - **加"跳过"按钮**：长消息（200+ 字）等待体验差，用户主动控制权
> - **TTS 按钮仅在打字完成后显示**：避免声音抢字速

## 手动测试步骤

### Step 1 · 开场白打字效果

1. 启动 App
2. 创建新精灵（或使用 demo 小雨）
3. 完成 onboarding 进入聊天页

**预期**：
- 开场白"你好啊。我有点……怎么说呢，像刚醒过来一样。今天，你想说什么？"逐字出现
- 文字末尾有琥珀色 2px 竖线闪烁
- 总时长约 35ms × 字数 ≈ 1.5s

### Step 2 · 用户消息 vs 助手消息对比

1. 在聊天页输入框输入"你好"
2. 点发送

**预期**：
- 用户消息"你好"**立即显示**（不走打字机）
- LLM 返回的助手消息**逐字显示**（走打字机）
- 助手消息带闪烁光标

### Step 3 · 长消息跳过按钮

1. 输入一个会引发长回答的问题，如"跟我讲讲你小时候的事"
2. 等待 LLM 返回长消息

**预期**：
- 长消息逐字出现（可能要 5-10s）
- 文字下方有"跳过 ›"按钮（小灰字 + 灰边框）
- 点击"跳过 ›"立刻显示完整消息，光标消失，"听 ta 说"按钮出现

### Step 4 · 历史消息不重打字

1. 退出 App
2. 重启 App
3. 重新进入聊天页

**预期**：
- 历史消息立即显示（不重打字）
- 只有 LLM 返回的新消息走打字机

### Step 5 · TTS 按钮时序

1. 触发一个助手消息走打字机
2. 打字中观察"听 ta 说"按钮

**预期**：
- 打字中**没有**"听 ta 说"按钮
- 打字完成后（或点"跳过"后）"听 ta 说"按钮才出现
- 点击"听 ta 说"立刻合成 TTS（不等任何延迟）

### Step 6 · 用户点击立触发的 greeting

1. 打字机完成后（或在历史消息状态下）
2. 点击聊天页中的精灵立绘

**预期**：
- 新 greeting 消息走打字机（如"你又来了。"）
- "听 ta 说"按钮在打字完成后才出现

### Step 7 · 异常 fallback 走打字机

1. 故意把 `lumora.txt` 内容改坏（或备份后清空）
2. 重启 App → 进入聊天页 → 发消息

**预期**：
- LLM 调用失败，fallback 消息"我现在有点恍惚，再说一遍好吗？"也走打字机
- 跟正常消息体验一致

### Step 8 · 节奏测试

1. 连续发 3-5 条消息
2. 每条都走打字机

**预期**：
- 每次打字完成后正确重置 `_typewriterIndex`
- 不会"卡在打字中"（后续消息也能走打字机）

## 已知问题

1. **Cursor 显示在文字末尾右侧**：当前实现是 Row(Text + 光标)，光标紧贴文字末尾。如果最后一行是长文本 wrap，光标位置在最后一行末尾——基本对，但极少数情况可能略有偏差（特别是中英混排）。
2. **ListView.builder 复用可能影响 State**：如果用户滚动列表导致 widget 重建，理论上会重启打字机。但 `ListView.builder` 复用 Element tree 的 State 时机是 widget 出现在可视范围时（onScreen），所以这种重建是"用户主动滚走又滚回"，行为符合预期。
3. **35ms/字是固定值**：没有按消息长度自适应。短消息（如"嗯"）也走 35ms/字有点拖沓；长消息（如 200+ 字）即使有"跳过"也可能偏慢。v2.3 评估自适应。
4. **光标颜色固定 amber**：没适配不同主题（Lumora 暂时只有深色主题，无问题）。
